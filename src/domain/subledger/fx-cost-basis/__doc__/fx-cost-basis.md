# FX Cost Basis Sub Ledger

See [FX Cost Basis Entity Invariants](invariants.md) for the bookkeeping and
data-reliability guarantees governing lots, acquisitions, dispositions, and
allocations, including the boundary between historical lot basis and financial
reporting measurements.

## Glossary

| Term                             | Definition                                                                                                                                                                                          |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FX Cost Basis Sub Ledger**     | The subledger that tracks foreign-currency holdings as cost-basis lots, then calculates realized and unrealized FX gain or loss.                                                                    |
| **`IMoney`**                     | A money value with an integer amount and a currency. In this subledger, quantity fields use the foreign currency, while basis/proceeds/gain fields use the accounting entity's functional currency. |
| **`IExchangeRate`**              | The exchange-rate value used to convert between the foreign currency and the functional currency.                                                                                                   |
| **`TEntityId`**                  | The shared entity identifier type used for domain records.                                                                                                                                          |
| **`Date`**                       | A JavaScript date value used for acquisition, disposition, creation, and update timestamps.                                                                                                         |
| **`null`**                       | Indicates that an optional relationship or rate is not available or has not yet been attached.                                                                                                      |
| **Functional currency**          | The primary currency in which an accounting entity measures its books and reports financial results.                                                                                                |
| **Foreign currency**             | Any currency other than the accounting entity's functional currency.                                                                                                                                |
| **`IFxCostBasisLot`**            | The mutable cost-basis layer for a foreign-currency holding. It stores the original acquired quantity, the remaining quantity, the original cost basis, and the remaining cost basis.               |
| **FX lot**                       | A cost-basis layer created by acquiring foreign currency at a specific rate and date.                                                                                                               |
| **`EFxCostBasisLotStatus`**      | The allowed status values for an FX lot.                                                                                                                                                            |
| **`UFxCostBasisLotStatus`**      | The TypeScript union type derived from `EFxCostBasisLotStatus`.                                                                                                                                     |
| **Open lot**                     | A lot with remaining foreign-currency quantity available for future disposition.                                                                                                                    |
| **Closed lot**                   | A lot whose full quantity has been consumed. Closed lots remain part of the audit trail.                                                                                                            |
| **`id`**                         | The unique identifier of the record.                                                                                                                                                                |
| **`ledgerAccountId`**            | The ledger account whose foreign-currency balance is tracked by the lot, acquisition, or disposition.                                                                                               |
| **`accountingEntityId`**         | The accounting entity that owns the FX lot activity and whose functional currency is used for cost basis and gain/loss.                                                                             |
| **`status`**                     | The current lot state, either `open` or `closed`.                                                                                                                                                   |
| **`originalQuantity`**           | The original foreign-currency amount acquired into the lot.                                                                                                                                         |
| **`remainingQuantity`**          | The foreign-currency amount still available in the lot after prior dispositions.                                                                                                                    |
| **Cost basis**                   | The functional-currency value assigned to a foreign-currency amount when acquired. Formula: `foreign amount * acquisition rate`, adjusted for the amount actually recognized.                       |
| **`costBasis`**                  | The original functional-currency cost basis recognized for the lot or acquisition.                                                                                                                  |
| **`remainingCostBasis`**         | The portion of the lot's cost basis that has not yet been consumed by dispositions.                                                                                                                 |
| **`acquisitionRate`**            | The exchange rate used when the foreign currency was acquired.                                                                                                                                      |
| **`acquisitionDate`**            | The date the foreign currency was acquired and the lot was created.                                                                                                                                 |
| **`createdAt`**                  | The timestamp when the record was created in Drimsheet.                                                                                                                                             |
| **`updatedAt`**                  | The timestamp when the mutable lot record was last updated.                                                                                                                                         |
| **`IFxCostBasisLotAcquisition`** | The immutable record of an increase in foreign-currency holdings that creates or supports an FX lot.                                                                                                |
| **Acquisition**                  | An increase in foreign-currency holdings, such as a purchase, deposit, conversion into the currency, receipt, or transfer in.                                                                       |
| **`lotId`**                      | The FX lot affected by an acquisition or allocation.                                                                                                                                                |
| **`journalEntryId`**             | The general-ledger journal entry associated with the acquisition or disposition, when one has been posted.                                                                                          |
| **`quantity`**                   | The foreign-currency amount acquired, disposed, or allocated, depending on the record type.                                                                                                         |
| **Official rate**                | A government, central bank, or tax-authority exchange rate. It should be used only when the applicable reporting or tax rule requires or accepts it.                                                |
| **`officialRate`**               | The official/statutory exchange rate captured for tax or statutory reporting, when different from the transaction rate.                                                                             |
| **Market rate**                  | The actual or observable exchange rate available in the market, often used for economic or operational reporting.                                                                                   |
| **Spot rate**                    | The exchange rate available for immediate exchange on a specific date.                                                                                                                              |
| **`IFxCostBasisLotDisposition`** | The immutable sale/decrease header for foreign-currency holdings. It records the total quantity disposed, proceeds, basis consumed, and realized gain or loss.                                      |
| **Disposition**                  | A decrease in foreign-currency holdings, such as a sale, conversion out of the currency, payment, settlement, transfer out, or adjustment.                                                          |
| **`costBasisConsumed`**          | The functional-currency cost basis removed from one or more lots by a disposition or allocation.                                                                                                    |
| **`proceeds`**                   | The functional-currency value received or recognized from the disposition.                                                                                                                          |
| **`realizedGainLoss`**           | The realized FX result on a disposition or allocation. Formula: `proceeds - costBasisConsumed`.                                                                                                     |
| **`dispositionRate`**            | The exchange rate used for the sale, conversion, payment, settlement, transfer out, or other disposition.                                                                                           |
| **`dispositionDate`**            | The date the foreign currency was disposed and realized gain or loss was measured.                                                                                                                  |
| **`IFxCostBasisLotAllocation`**  | The immutable link between a disposition and the FIFO lot or lots consumed by that disposition.                                                                                                     |
| **Lot allocation**               | The mapping from one disposition to the specific lot quantity consumed. Under FIFO, one disposition may have multiple allocations.                                                                  |
| **`dispositionId`**              | The disposition header that an allocation belongs to.                                                                                                                                               |
| **Cost-flow method**             | The rule used to decide which lots are consumed by a disposition. Drimsheet's FX lot model is expected to use FIFO for this jurisdictional flow.                                                    |
| **FIFO**                         | First in, first out. The oldest open lots are consumed before newer lots.                                                                                                                           |
| **LIFO**                         | Last in, first out. The newest available lots are consumed first, if permitted by the accounting or tax rules being applied.                                                                        |
| **Weighted-average cost**        | A method that treats holdings as having one blended average acquisition rate instead of tracking gain or loss against each individual lot.                                                          |
| **Specific identification**      | A method where the user explicitly chooses which lots are consumed by a disposition.                                                                                                                |
| **Carrying amount**              | The current book value of a foreign-currency balance in functional currency.                                                                                                                        |
| **Current value**                | The functional-currency value of a remaining foreign-currency amount using the current or reporting exchange rate. Formula: `foreign amount * current rate`.                                        |
| **Closing rate**                 | The exchange rate at the reporting date, used to remeasure open foreign-currency monetary balances.                                                                                                 |
| **Reporting date**               | The date on which balances are remeasured for financial statements or internal reports.                                                                                                             |
| **Realized FX gain/loss**        | Gain or loss recognized when foreign currency is disposed. Formula: `proceeds - costBasisConsumed`.                                                                                                 |
| **Unrealized FX gain/loss**      | Gain or loss on foreign currency still held, based on current/reporting value compared with remaining cost basis. Formula: `current value - remaining cost basis`.                                  |
| **Remeasurement gain/loss**      | Accounting term often used for unrealized FX gain/loss on foreign-currency monetary items revalued at a reporting date.                                                                             |
| **Book-basis FX gain/loss**      | FX gain/loss calculated for financial reporting or internal ledger purposes.                                                                                                                        |
| **Tax-basis FX gain/loss**       | FX gain/loss calculated using the rules and exchange rates required by the relevant tax authority.                                                                                                  |
| **Economic FX gain/loss**        | FX gain/loss calculated using actual market or execution rates for management/internal reporting.                                                                                                   |
| **Audit trail**                  | The historical record of acquisitions, dispositions, allocations, and rate assumptions used to explain reported gains and losses.                                                                   |
